# Period Tracker - 女性经期追踪管理应用

## 项目简介

Period Tracker 是一款简洁易用的女性经期追踪管理应用，帮助用户记录和预测月经周期。

## 功能特性

- 📅 记录月经开始/结束日期
- 📊 周期统计和趋势分析
- 🔮 预测下次月经日期
- 🌡️ 记录基础体温
- 📝 记录症状和情绪变化
- 🔔 经期提醒功能
- 📱 响应式设计，支持移动端

## 技术栈

- HTML5 / CSS3 / JavaScript
- LocalStorage 本地数据存储
- 纯前端应用，无需后端

## 快速开始

直接在浏览器中打开 `index.html` 即可使用。
